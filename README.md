# 恣优 FlowIn

**AI时代，让自由成为一种工作方式。**

FlowIn 是一个连接组织与人才、组织与人的人才与机会社区。

我们希望帮助每个人发现可以做的事、被看见、与他人建立连接，并找到自己的下一步。

## 🌊 我们在做什么

FlowIn 正在探索 AI 时代更加灵活、开放、以人为本的工作方式，让人才与机会建立更自然的连接。

我们关注：

- 项目制工作与自由职业机会
- 人才、创业者与组织之间的连接
- AI 时代的新型工作方式
- 让更多人的能力被看见

## 🤝 参与 FlowIn

欢迎对产品、设计、开发和 AI 时代工作方式感兴趣的伙伴参与建设。

你可以：

- 在 GitHub Issues 中提出问题或建议
- Fork 本仓库，尝试改进代码
- 提交 Pull Request，与我们一起完善 FlowIn

请在提交 PR 时简单说明修改目的和影响范围。所有修改都会经过项目维护者审核。

## 🚀 项目状态

FlowIn 仍在持续开发中，部分功能和技术方案可能会发生变化。欢迎关注项目进展并参与讨论。

## 📬 联系与交流

欢迎通过 GitHub Issues 与我们交流，一起探索 AI 时代人与机会连接的新可能。

# ❤️ 支持 FlowIn

FlowIn还很小，为了帮到更多人，TA的成长需要更多人的支持。
如果你认同 FlowIn 的理念，欢迎自愿支持项目的持续开发。

感谢每一位关注、参与和支持 FlowIn 的伙伴！
